# 棱镜双轴四层 · 整体框架

> 这份文件是"双轴四层"的总览。具体每一层怎么写、怎么写到位、怎么避免伪结构层/范式层，分别去 `structure-layer-questions.md`、`paradigm-layer-questions.md`。两个元透镜（反身性、同构）见 `reflexivity-lens.md` 和 `isomorphism-lens.md`。

## 一、整体心智模型

理解一个领域，**不是只看正在发生什么**——那只是事件层（event）。一个领域真正的样子，要从四个时间尺度同时看：

```
┌──────────────────────────────────────────────────────────────────┐
│              纵轴（时间纵深）           横轴（跨领域同构）          │
│  ┌────────────────────────┐                                      │
│  │ 范式层（一代人）         │  ← 信念/世界观/世代经验             │
│  │ 结构层（5–10 年）       │  ← reality-shaping 约束            │ → 邻接领域
│  │ 机制层（季度–年）        │  ← 商业模式/壁垒/规模效应           │ → 历史时期
│  │ 现象层（天–月）          │  ← 事件/玩家/拐点                   │ → 跨尺度
│  └────────────────────────┘                                      │
│                                                                  │
│  叠加两个元透镜：                                                  │
│  · 反身性：参与者认知影响领域，领域反过来塑造认知                     │
│  · 同构：相邻领域 / 历史时期 / 跨尺度的结构性相似                    │
└──────────────────────────────────────────────────────────────────┘
```

**关键直觉**：一个领域如果只在一层上分析，就一定写残。AI 大模型在事件层（每周新模型发布）和在范式层（智能是不是计算？）看到的是完全不同的两个领域。

## 二、四层总览表

> 暗箭工具：纵轴的"四层时间常数"思路，灵感来自历史学派对"短时段事件 / 中时段周期 / 长时段结构"的三分，外加一层范式信念层。

| 层 | 主要回答的问题 | 主要工具 | 时间常数 | 输出形态 |
|---|---|---|---|---|
| **现象层** | 现在发生了什么？谁在场？最近的拐点在哪？ | 时间轴、玩家地图、新闻索引、近 12 个月里程碑表 | 天 / 月 / 季度 | 大事记、玩家清单、近期热点 |
| **机制层** | 这个领域怎么挣钱／怎么运转？壁垒从哪来？规模效应在哪？ | 商业模式画布、五力解构、壁垒七问、单位经济 | 1–3 年 | 价值链图、商业模式注解、利润池分布 |
| **结构层** ⭐ | 为什么这个领域必须长成这样？哪些约束是无法绕过的？ | reality-shaping 约束清单、演化象限、长时段对比 | 5–10 年 | 约束地图、不可变陈述、形态决定论分析 |
| **范式层** ⭐ | 这个领域处于哪种范式时期？硬核是什么？异端在哪？ | 范式时期判别、硬核-保护带、技术革命周期定位 | 一代人（20–40 年） | 范式现状陈述、硬核与保护带列表、上一次革命的时间 |

注解：

- **现象层** 容易写，但容易写成新闻汇编。判断现象层到位的标准：能不能找出"看似无关的两件事其实是同一条主线"。
- **机制层** 是写作密度最高的一层。机制层不是"画几个箭头"，要给出**单位经济能不能走通**、**护城河来自第几条**这种可证伪的陈述。
- **结构层 ⭐** 是分水岭。绝大多数"领域分析"卡在机制层。如果结构层只是机制层换个说法（"行业格局是寡头"）就属于伪结构层——详见 `structure-layer-questions.md`。
- **范式层 ⭐** 最容易写空。需要在"判别当前处于哪个范式时期"上给出明确的判据，而不是排比"未来已来"。详见 `paradigm-layer-questions.md`。

## 三、横轴：跨领域同构（一把抓）

横轴只有一道关：能不能从**至少两个不同来源**找到同构案例，并给出"同构点 + 反同构点"。

```
┌──────────────────────────────────────┐
│ 同构来源（必须 ≥2 个不同来源）          │
├──────────────────────────────────────┤
│ a. 历史时期同构                        │
│    例：电力革命 → AI 革命              │
│        铁路狂热 → 互联网泡沫           │
│ b. 邻接领域同构                        │
│    例：搜索引擎分发 → 大模型分发        │
│        流媒体内容 → AI 助手内容         │
│ c. 跨尺度同构                          │
│    例：个体生命周期 → 行业生命周期      │
│        细胞代谢 → 公司现金流           │
└──────────────────────────────────────┘
```

每个同构都要给"反同构点"——哪里不像，可能致命到推翻类比。详细方法见 `isomorphism-lens.md`。

## 四、时间尺度套利（最容易被忽略的杠杆）

四层各有时间常数，**判断"领域走向"时必须先确定在哪个时间尺度上判断**。这是写出有信息量的判断的前提。

| 时间尺度 | 现象层 | 机制层 | 结构层 | 范式层 |
|---|---|---|---|---|
| **看 1 个月** | 大量信号 | 噪声 | 完全不动 | 完全不动 |
| **看 1 年** | 已成历史 | 主要信号 | 微弱信号 | 噪声 |
| **看 5 年** | 已忘记 | 已成历史 | 主要信号 | 微弱信号 |
| **看 20 年** | 完全无关 | 已洗牌 | 已成历史 | 主要信号 |

> 暗箭工具：**长时段（longue durée）vs 中时段 vs 事件**——历史学派把人类活动分成三层时间；范式层这一格再上加一层"世代信念"。

实战含义：

- 用户问"AI 大模型领域 3 年内会怎样" → 主要在机制层 + 部分结构层回答，范式层只能给"是不是已经进入异常期"的判断。
- 用户问"AI 大模型 20 年后什么样" → 主要在范式层回答，机制层是噪声（具体哪家公司赢不重要）。
- 用户问"向量数据库下季度热点" → 现象层 + 机制层，结构/范式层完全不要展开——展开就是水。

**反模式**：把所有问题都拉到范式层回答。"AI 现在怎么了？"用"我们正处于范式革命前夜"这种宏大叙事回答 = 没回答。

## 五、四层走查 demo（向量数据库领域，~150 字）

> 用一个具体领域走一遍四层。读完应该能感受到层与层的差异。

- **现象层**：2023–2024 Pinecone、Weaviate、Milvus、Qdrant 等公司融资集中爆发；同期 PostgreSQL `pgvector` 扩展、Elastic、MongoDB 都加了向量字段；2024 起独立向量数据库估值回调。
- **机制层**：核心是 ANN 索引（HNSW、IVF 等）的工程化封装。盈利依赖"嵌入数据规模 × 查询 QPS"。壁垒来自索引算法精度 + 分布式工程 + 数据 gravity。
- **结构层**：reality-shaping 约束是"嵌入向量的存储和检索可以由通用数据库内置完成"。这一约束意味着独立向量数据库长期面临**被吸收进通用 DB 的命运**。形态被这一条决定了：要么成为通用 DB 的一个能力，要么垂直深耕（如多模态、长上下文检索）。
- **范式层**：当前处于"检索范式正在被生成范式蚕食"的过渡期——RAG 是当前主导范式，但智能体 + 长上下文模型在挑战"检索作为独立环节"的必要性。这一层的问题已经超越了"哪家向量数据库会赢"。

四层一摆，读者应该能看出：**事件层在讲谁融了多少钱，机制层在讲怎么挣钱，结构层在讲为什么这个品类长期会被压扁，范式层在讲这个品类是不是会消失**。这不是同一个问题的不同说法——是四个完全不同的问题。

## 六、四层之间的"上下游负责"关系

```
┌──────────┐  解释  ┌──────────┐  约束  ┌──────────┐  驱动  ┌──────────┐
│ 范式层    │ ────→ │ 结构层    │ ────→ │ 机制层    │ ────→ │ 现象层    │
└──────────┘        └──────────┘        └──────────┘        └──────────┘
                              ←────  穿透  ────
```

写作时**自下而上**收集事实（先有现象，再归纳机制），但**自上而下**组织叙述（用范式解释结构，用结构解释机制，用机制解释现象）。这两个方向倒过来用：自上而下收集事实容易陷入选择性举证，自下而上组织叙述容易写成流水账。

## 七、何时用哪一层（决策指引）

| 用户问题形态 | 主战场 | 辅助层 |
|---|---|---|
| "XX 现在怎么了" | 现象 | 机制 |
| "XX 怎么挣钱" | 机制 | 现象 |
| "XX 为什么是现在这样" | 结构 | 机制 + 范式 |
| "XX 5 年后会变成什么" | 结构 | 范式 |
| "XX 这个品类是不是会消失" | 范式 | 结构 |
| "XX 跟历史上的 YY 像不像" | 横轴同构 | 范式 |
| "XX 的主流叙事可信吗" | 反身性元透镜 | 现象 + 结构 |

> 写作时如果发现自己在某一层"无话可说"，是诊断信号——不是放弃这一层，是去补事实。无话可说 = 没读够素材。
