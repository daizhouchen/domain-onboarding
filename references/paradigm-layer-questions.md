# 范式层提问范式

> 范式层（paradigm layer）是最容易写空的一层。范式层的失败模式是把"未来已来 / 时代变了 / 一切都将被重新定义"排比一通——这种写法零信息量。本文给 5 个必问的范式层问题，每个都有判据、正例、反例。

## 一、范式层为什么容易写空

范式层回答的是：**这个领域目前处于什么阶段的世界观？信念是什么？信念将如何被打破？**

它的难点是：**范式不是观点，是参与者的"默认设置"——他们不知道自己有这个信念**。写范式层的人如果只是看舆论场，会把"主流叙事"当成范式——主流叙事可能是范式的表达，也可能根本不是范式而只是当期热点。

> 暗箭工具：**范式时期四分（前范式 / 常规 / 异常 / 革命）+ 硬核-保护带 + 技术革命周期（导入期 / 拐点 / 协同期 / 成熟期）**。这三套工具叠加，能避免"未来已来"式空话。

## 二、5 个必问的范式层问题

### Q1. 当前处于哪种范式时期？

**问题表述**：这个领域目前处于"前范式 / 常规科学 / 异常累积 / 范式革命"的哪一段？

**到位标准**：
- 必须给出**判据**，不只是结论
- 判据要带可观察信号——主流模型 vs 异端的分布、跨学派对话能否发生、是否有"危机感"
- 不要四个时期都说一遍，要押一个

```
┌─────────────────────────────────────────────┐
│ 范式时期判据                                  │
├─────────────────────────────────────────────┤
│ 前范式期：多个流派并立，无主导框架            │
│   信号：术语不统一，每个学派从头解释一切      │
│ 常规期：单一框架主导，所有玩家在同一框架内竞争 │
│   信号：成功 = 用主导框架做出更好的实例        │
│ 异常期：异常案例累积，但还在用主导框架修补    │
│   信号：开始出现"X 不能解释 Y"的讨论          │
│ 革命期：新框架出现并争夺主导地位              │
│   信号：圈外人开始挑战圈内规则，且赢          │
└─────────────────────────────────────────────┘
```

**正例**（自动驾驶领域，2024 年视角）：
> "处于'异常期'晚期：主导范式（HD 高精地图 + 多传感器融合 + 模块化 pipeline）正在被异常压力冲击——特斯拉 FSD v12 的'端到端神经网络 + 视觉为主'路线在多个边角案例上反超模块化方案，且整个产业开始讨论'要不要扔掉高精地图'。距离全面革命还差一步：新范式还没在所有场景上证明自己。"

**反例**：
> "自动驾驶正在迎来变革。"——零判据、零信号、零信息。

### Q2. 主导范式的"硬核"是什么？

**问题表述**：当前主导范式不可放弃的核心信念是什么？放弃了，就不是这个范式了。

**到位标准**：
- 硬核是**信念性陈述**，不是技术细节
- ≤3 条，多了不是硬核
- 必须能解释"为什么这个领域当前所有玩家都默认接受这一信念"

> 暗箭工具：**硬核（hard core）vs 保护带（protective belt）**——研究纲领由不可放弃的硬核信念和可调整的辅助假设构成。

**正例**（AI Infra 领域）：
> "当前主导范式的硬核三条：①智能可以由参数规模 × 数据规模 × 算力规模线性放大达成（scaling law 信念）；②自然语言是通用接口（一切交互最终走 chat）；③Transformer 是当前唯一可商用的通用基础架构。这三条任何一条被推翻，'AI Infra'这个品类的整个投资逻辑都要重写。"

**反例**：
> "AI Infra 的核心是 GPU。"——这是技术细节，不是信念。

### Q3. "保护带"——可放弃的外围有哪些？

**问题表述**：哪些是当前范式可以丢弃用来自救的外围假设？

**到位标准**：
- 必须区分"硬核"vs"保护带"——保护带可调整、硬核不能动
- ≥3 条保护带
- 给出"放弃这条意味着什么"

**正例**（AI Infra 领域）：
> "可放弃的保护带：①'必须用 NVIDIA GPU'——可放弃，已经在向 ASIC、TPU、AMD 分散；②'必须用 Transformer'——SSM、Mamba、混合架构都在尝试，可放弃；③'必须 dense 模型'——MoE 已成主流，dense 可放弃；④'必须从零训练'——全部转向 fine-tune + RAG + agent。这些放弃中的每一条都是为了保住硬核三条（scaling、自然语言接口、规模驱动智能）。"

**反例**：
> "AI Infra 在不断演进。"——没有硬核-保护带区分，没有放弃成本。

### Q4. 异端在哪里？挑战的是硬核还是保护带？

**问题表述**：当前对主导范式提出最严肃挑战的异端是谁？他们攻击的是硬核还是只在动保护带？

**到位标准**：
- 至少 2 个具体异端方向（不是公司名，是技术 / 哲学方向）
- 必须区分"动了硬核"和"只动了保护带"——这是**质的区别**
- 评估异端的"赢面"——已经赢了？接近赢？还在边缘？

**正例**（AI Infra 领域）：
> "异端方向：①世界模型 + 具身智能（LeCun 路线）——攻击硬核中的'语言为通用接口'，主张感知-行动闭环优先于语言。这是动硬核的，目前还在边缘。②小模型 + 后训练优化路线——攻击硬核中的'规模线性放大'，主张过了某个尺寸 RL + 数据质量的回报远高于继续 scale。这是接近动硬核的，2024–2025 已经在部分基准上证明了自己。③符号 + 神经混合——攻击的是保护带（'必须纯神经'），不是硬核。"

**反例**：
> "有些公司在尝试不同的路线。"——没有挑战层级、没有赢面评估。

### Q5. 这个领域上一次范式革命发生在什么时候？

**问题表述**：上一次这个领域发生过范式革命是什么时候？当时硬核换了什么？革命经过几个阶段？

**到位标准**：
- 给出**具体年份**，不是"很多年前"
- 给出**新旧硬核的具体替换内容**
- 给出"革命用了多少年"——这是判断当前距离下一次革命距离的参考

> 暗箭工具：**技术革命周期四阶段（导入期 / 拐点 / 协同期 / 成熟期）**——每次大革命大约用 50–60 年走完，前后期生态完全不同。

**正例**（AI 大模型领域）：
> "上一次范式革命：2012–2017 年。旧硬核：'AI 是符号推理 + 专家系统 + 特征工程'；新硬核：'AI 是端到端可微分 + 大数据驱动 + 表示学习'。导火索：2012 年 ImageNet AlexNet 击败传统方法 10 个百分点；拐点：2017 年 Transformer 发表，跨任务通用架构出现；协同期：2018–2022 年 BERT、GPT 系列、扩散模型在所有方向开花；当前进入成熟期早段（2022– ）。一次革命大约用了 10 年从导火索到成熟，下一次（如果硬核被推翻）保守估计也要 5–10 年。"

**反例**：
> "AI 一直在进步。"——没有上一次范式、没有时间尺度、没有阶段划分。

## 三、AI Infra 领域 5 问 demo

走一遍上面 5 个问题在同一个领域的回答（精简版，~250 字）：

> **Q1**：异常期早段——scaling law 仍主导，但 GPT-4o → o1 → R1 系列出现的"推理时计算"和小模型蒸馏路线已经开始累积异常。**Q2**：硬核三条：scaling 假设 / 自然语言接口 / Transformer 通用性。**Q3**：保护带——NVIDIA GPU 锁定、dense 架构、从零预训练，这三条已在松动。**Q4**：异端——世界模型路线（动硬核，边缘）、推理时计算路线（接近动硬核，正在赢）、状态空间模型（混合，部分挑战 Transformer 通用性，未赢）。**Q5**：上一次革命 2012–2017，从特征工程到表示学习，10 年完成。当前距离下一次革命的判断取决于硬核三条里哪一条先被推翻——大概率是"scaling 线性放大"先松动。

读完应该能感受到：范式层不是排比未来已来，是**有判据、有信念识别、有时间尺度、有异端定位**的具体分析。

## 四、范式层写作禁忌

不要写的句式：

- "未来已来 / 时代变了 / 重新定义"
- "AI 将颠覆一切"
- "这是百年未有之大变局"
- "范式正在转变"（没说从什么转到什么）
- "我们正处于历史性时刻"

要写的句式：

- "硬核是 X、Y、Z 三条；保护带正在松动 A、B、C"
- "异端在攻击 [硬核某条]，距离推翻还差 [具体证据]"
- "上一次范式革命发生在 [年份]，从 [旧硬核] 转到 [新硬核]，用了 [时长]"

## 五、范式层与结构层的衔接

```
范式层（信念）→ 决定 → 结构层（约束）→ 决定 → 机制层（玩法）
```

写作时：先在结构层把约束写清楚，再回到范式层问"这些约束背后的默认信念是什么"。如果结构层写得清楚，范式层有迹可循；如果结构层都没写清楚，范式层一定写空。

**自检**：写完范式层，倒回去问——这一层的陈述如果是错的，结构层和机制层会怎么变？答得出来，是真范式层；答不出来，是空话。
