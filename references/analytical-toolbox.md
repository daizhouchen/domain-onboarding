# 分析工具箱 · Analytical Toolbox

> 工具箱原则：**何时调哪把刀，比把所有刀都磨亮更重要**。
> 这里是 12+ 把分析刀的"调度表"——告诉模型：什么领域、什么层次、什么问题，应该挑哪一把。
> 标注的学者名只在工具箱内部用，**正文 HTML 一律不准出现**（见 `method-internalization.md`）。

---

## 使用规则（先读这一段）

```
┌──────────────────────────────────────────────────────────┐
│  Step 1  先识别"问题在棱镜的哪一层"（现象/机制/结构/范式/元）│
│  Step 2  从对应层的工具组里选 1-2 把（不要叠满，叠满=学究腔）│
│  Step 3  用工具的"思考方式"分析，但产出时**翻译成业务语言** │
│  Step 4  如果一把刀切不动 → 换刀，不要硬切                  │
└──────────────────────────────────────────────────────────┘
```

- 一篇 HTML 平均**调用 3-5 把刀**就够了，超过 7 把通常是堆砌。
- 工具是"看问题的角度"，不是"贴在结论上的标签"。
- 同一层多把刀冲突时，**优先选给出更具体证伪条件的那一把**。

## 工具卡片（12 把）

### 1. 五力分析 · Porter's Five Forces
- 来源：Michael Porter, 1979（仅工具箱内部记，不写进正文）
- 解决什么问题：**为什么这个行业的利润率长期被锁定在某个区间**
- 用在哪一层：**结构层**（约束行业上限）
- 怎么用（5 步）：
  1. 列出该行业现有玩家、上游、下游、潜在进入者、替代品（5 个名单）
  2. 给每个名单打"议价能力"分（强/中/弱）+ 一句证据
  3. 找出"最强的那一个力" — 那就是这个行业的利润瓶颈
  4. 反向问：如果我是新玩家，我攻哪一边能撕开口子？
  5. 时间维度：5 年前这五力分布是什么样？现在变了什么？
- 适用领域：**商业、传统行业、To B SaaS**（结构稳定的领域）
- 应用 demo（向量数据库行业，约 130 字）：
  上游是 GPU 厂商（NVIDIA 一家独大，议价能力极强 → 自营机房成本高）；下游是大模型应用层（极度分散 + 客户高粘性，但价格敏感）；现有玩家 Pinecone/Weaviate/Milvus 拼搜索召回率，差异化弱；替代品最危险——Postgres 的 pgvector 已经把 80% 简单场景吃掉了，**这是这个行业利润率被压制的真正原因**。新进入者唯一活路是吃下"GPU 上游议价"或者跳到 DB 自带 vector 的范式。
- **不适用**：新兴领域、范式正在迁移的领域、网络效应主导的领域（五力会让你低估"赢家通吃"的速度）

### 2. 7 Powers
- 来源：Hamilton Helmer
- 解决什么问题：**已经赢了的公司，凭什么持续赢**（不是为什么会赢，是为什么挡得住后来者）
- 用在哪一层：**机制层 → 结构层之间**
- 怎么用：
  1. 对照 7 种力源（规模经济、网络效应、反向定位、转换成本、品牌、垄断资源、流程力）
  2. 每一种问"该公司有这种力吗？证据是什么？力有多深？"
  3. 区分"Power"（持续护城河）vs"Benefit"（暂时优势）—— 多数人会把 Benefit 误判为 Power
- 适用领域：**商业、平台经济、被巨头主导的领域**
- 应用 demo（向量数据库，约 120 字）：
  Pinecone 早期被认为有"先发优势"，但用 7 Powers 看：规模经济弱（云服务商可平替）、网络效应几乎为零（向量库不依赖其他用户）、转换成本中等（迁移痛但可做）、品牌弱、流程力弱。**结论：Pinecone 没有任何一种 Power**，估值只能靠预期支撑。这解释了 2024 年估值回调。
- **不适用**：早期未盈利的领域、To C 文化领域（粉丝经济不在七力里）

---

### 3. 创新者窘境 · The Innovator's Dilemma
- 来源：Clayton Christensen
- 解决什么问题：**为什么管理良好的领先公司会被低端入侵者颠覆**
- 用在哪一层：**机制层 + 演化层**
- 怎么用：
  1. 找该领域"低端市场"——领先者主动放弃或不屑于做的部分
  2. 看是否有"足够便宜但够用"的新方案出现在低端
  3. 看新方案的性能曲线是否爬得比客户需求曲线快
  4. 警告：很多被滥用为"颠覆=好"——真正的颠覆是技术轨迹错位，不是营销口号
- 适用领域：**技术领域、硬件、SaaS**
- 应用 demo（向量数据库）：
  pgvector 是教科书级的低端颠覆——刚出来时性能差、功能少、被 Pinecone 之流嘲笑"不够 production"，但它**够便宜（已经在 Postgres 里）+ 够用（80% 场景延迟可接受）**，性能曲线在 2 年内追上了中端需求线。这不是"竞品出现"，这是 Christensen 模型的精确再现。
- **不适用**：奢侈品领域（高端不会被低端颠覆，高端被新高端颠覆）、文化产品（颠覆逻辑不同）

### 4. Wardley Map
- 来源：Simon Wardley
- 解决什么问题：**现在你的技术栈每个组件，处于"创世/定制/产品/商品"哪一格**
- 用在哪一层：**演化层（时间轴）+ 结构层（依赖图）**
- 怎么用：
  1. 画 X 轴：creation → custom-built → product → commodity
  2. 画 Y 轴：用户可见度（顶端是用户、底端是基础设施）
  3. 把领域里的关键组件全部点到坐标上
  4. 画箭头：每个组件未来 3 年会向右移多远
  5. 找"即将商品化"的组件——那是最危险也最有机会的位置
- 适用领域：**技术、基础设施、平台战略**（这把刀几乎是技术领域必用）
- 应用 demo（向量数据库）：
  2021 年 vector DB 是 product 阶段，2024 年正在快速向 commodity 滑（pgvector + 云厂自带），而上面的 embedding model（OpenAI / Cohere）反而从 product 滑回 utility（按 token 收费）。**整个栈在 2 年内向右移了 1.5 格**。Pinecone 卡在中间不上不下，这才是它的真正困境。
- **不适用**：纯文化、纯监管、纯人际关系领域（演化轴对它们意义不大）

---

### 5. 技术革命周期 · Technological Revolutions
- 来源：Carlota Perez
- 解决什么问题：**这个技术处于"安装期/疯狂期/转折点/部署期/成熟期"哪个阶段**
- 用在哪一层：**范式层**
- 怎么用：
  1. 画 50 年尺度的 S 曲线（不是 5 年的小波动）
  2. 找"金融资本"和"生产资本"的脱节点——疯狂期就在这里
  3. 找"转折点"标志：监管介入、资本退潮、第一批死亡名单
  4. 部署期看"协同期生产率红利"——这是真正的赚钱时期，但慢
  5. 注意：S 曲线不是命运，可以被政策/战争打断
- 适用领域：**技术领域必用、宏观投资、宏观政策**
- 应用 demo（生成式 AI 整体，约 130 字）：
  2022.11-2024.Q3 是经典疯狂期：估值脱实向虚（OpenAI 估值 / 收入比离谱）、人才流动剧烈、垂直应用层"一周一个独角兽"。**转折点信号**：2024 末算力短缺缓解 + 监管硬约束（EU AI Act）+ 第一批 AI 应用公司死亡名单出现。Perez 模型预测：未来 5-10 年是"协同期"，赚钱的不再是模型公司，而是把 AI 嵌进存量业务的 incumbents。
- **不适用**：消费时尚、艺术流派（这些有自己的周期模型）

### 6. 三层时间 · Longue Durée
- 来源：Fernand Braudel
- 解决什么问题：**这个领域的事件、周期、结构分别处于哪个时间尺度**
- 用在哪一层：**结构层（结构性约束）+ 范式层**
- 怎么用：
  1. 三层切片：事件层（< 5 年）/ 周期层（10-50 年）/ 结构层（> 100 年甚至千年）
  2. 把领域里的"现象"全部放到三层中的某一层
  3. 警告：90% 的新闻在事件层，但能赚钱/避险的洞察 80% 在周期层和结构层
  4. 识别"伪结构"——很多看似永恒的东西其实只是周期
- 适用领域：**金融、宏观、地缘、文化、社会学**
- 应用 demo（中国房地产）：
  事件层：某城限购放松（< 1 年）；周期层：2008-2021 货币宽松带来的资产通胀（13 年）；结构层：城市化率 + 人口结构 + 土地财政体制（30-50 年）。**多数人在交易事件层，但事件被周期框住，周期被结构锁死**。如果只看事件层，就会反复被"利好/利空"晃。
- **不适用**：严格意义的技术细节领域（千年视角对一个具体算法没用）

### 7. 反身性 · Reflexivity
- 来源：George Soros
- 解决什么问题：**当参与者的认知本身改变了被认知对象的时候，会发生什么**
- 用在哪一层：**元透镜（叠加在所有层之上）**
- 怎么用（5 步）：
  1. 识别"主流叙事"是什么（一句话能说清的版本）
  2. 谁在传播？媒体/分析师/带头人/政策？
  3. 这个叙事如何**自我证实**——叙事 → 资金/行为 → 现实 → 反过来加强叙事？
  4. 失效条件：什么情况会让自我证实链条断掉？
  5. 反过来还有"反身性反转"——叙事越强，反弹越剧烈
- 适用领域：**金融领域必用**、宏观、政治、舆论场、加密货币
- 应用 demo（GameStop 2021）：
  主流叙事："散户抱团对抗对冲基金"。这个叙事吸引散户买入 → 推高股价 → 媒体报道更多 → 更多散户进场 → 形成反身性正循环。失效条件：清算所提保证金（Robinhood 暂停买入）→ 故事断裂。**反身性的本质是：故事不是描述现实，故事就是现实的一部分。**
- **不适用**：物理化学之类客观规律领域（反身性需要"参与者认知"作为变量）

### 8. 双系统 · Thinking Fast and Slow
- 来源：Daniel Kahneman
- 解决什么问题：**领域内的玩家在哪些决策上靠 System 1（直觉），哪些靠 System 2（分析）**
- 用在哪一层：**机制层（行为机制）**
- 怎么用：
  1. 列出该领域的"典型决策点"
  2. 标注每个点是 System 1 还是 System 2 主导
  3. System 1 主导的决策点 → 找认知偏差（锚定/可得性/损失厌恶）
  4. System 2 主导的决策点 → 找信息不对称
  5. 套利机会通常在"市场以为是 System 2 但其实是 System 1"的地方
- 适用领域：**金融、消费、UX 产品设计、营销**
- 应用 demo（IPO 定价）：
  市场以为 IPO 定价是 System 2（投行做估值模型），但实际上**机构路演反馈中 70% 是 System 1**（最近一次类似 deal 的"感觉"作为锚定）。这解释了为什么 IPO 定价会出现群体性偏差——锚定到上一个热门 deal。
- **不适用**：纯数学/算法领域（没有人类参与者就没有偏差）

---

### 9. 黑天鹅 + 反脆弱 · Antifragility
- 来源：Nassim Taleb
- 解决什么问题：**这个领域对"罕见极端事件"的暴露形态是什么**
- 用在哪一层：**结构层（风险结构）**
- 怎么用：
  1. 找该领域的"非线性收益曲线"——上行/下行不对称在哪
  2. 区分三态：脆弱（小波动累积成大崩）、鲁棒（不变）、反脆弱（波动变强）
  3. 找"长尾事件"——百年一遇是不是其实是十年一遇？
  4. 警惕"看似稳定其实在累积尾部风险"的领域
  5. 反向操作：在脆弱领域反向押注、在反脆弱领域加杠杆
- 适用领域：**金融领域必用**、风险管理、生物医药、地缘
- 应用 demo（稳定币 UST 崩盘前）：
  UST 的"算法稳定"叙事制造了脆弱——年化 20% 收益看似稳定，但收益机制依赖**永不停止的新进入者**，这是经典 Ponzi 形态的脆弱。一次 5 亿美元的协调卖出就触发死亡螺旋。事前征兆：尾部对冲成本接近 0（市场不相信会崩 = 最危险的信号）。
- **不适用**：周期短、可重复采样的领域（A/B 测试场景）

### 10. 二阶思维 · Second-Order Thinking
- 来源：Howard Marks / Michael Mauboussin
- 解决什么问题：**别人都在想"X 会发生"，但你要想"X 发生之后大家会怎么反应"**
- 用在哪一层：**机制层 + 元透镜**
- 怎么用：
  1. 一阶："如果 A 发生，会怎样"
  2. 二阶："所有人都知道 A 会发生，价格已经反映了，那真正的边际收益从哪来？"
  3. 三阶："所有人都在做二阶，那二阶的 alpha 也消失了，怎么办？"
  4. 应用："共识是什么？反共识里哪个是合理的？"
  5. 警惕：二阶思维容易过度，变成阴谋论
- 适用领域：**金融、博弈密集型行业、投资分析**
- 应用 demo（AI 应用层投资）：
  一阶："大模型很强，AI 应用一定爆发"——所有 VC 都这样想。二阶：所有人都在投 AI 应用 → 估值过高 + 同质化 + 模型公司向下卷，应用层利润被两头挤压。**真正的二阶 alpha 在"反共识但合理"——比如投做"AI 失败后的兜底服务"的公司**。
- **不适用**：早期不存在共识的新兴领域

### 11. 网络效应 + Reed 定律
- 来源：Metcalfe / David Reed / Andrew Chen 综合
- 解决什么问题：**这个领域的网络效应是哪一型，强度多大**
- 用在哪一层：**机制层（壁垒机制）**
- 怎么用：
  1. 区分网络效应类型：直接（电话型）/ 间接（双边平台）/ 数据网络（推荐算法型）/ 社交网络（Reed 定律 N²ⁿ）
  2. 量化"用户加 1 的边际价值"
  3. 找临界质量点 = 网络效应启动门槛
  4. 找"反网络效应"——拥挤、噪音、变质
  5. 评估"可移植性"——用户能不能带着关系网走（决定锁定强度）
- 适用领域：**平台经济、社交、SaaS、双边市场**
- 应用 demo（推特 vs Threads vs Bluesky）：
  推特是社交网络（Reed 型，2ⁿ），关系网移植成本极高 → Threads 用 Instagram 关系图绕过冷启动 → Bluesky 走"用户自带域名"的可移植路线。**三个产品对应三种破解 Reed 定律锁定的策略**：嫁接、协议化、个体可移植。
- **不适用**：单边产品（普通 SaaS 工具）、内容消费类（看视频不需要别人看）

### 12. 博弈分析 · Schelling + 协调/背叛
- 来源：Thomas Schelling
- 解决什么问题：**多方互不信任时，会聚焦在哪个"焦点"上达成默契**
- 用在哪一层：**结构层（博弈结构）**
- 怎么用：
  1. 识别博弈类型：协调（双赢）/ 零和 / 囚徒困境 / 多人重复
  2. 找 Schelling Point——没有沟通时大家都会选的"显眼默认值"
  3. 列出每个玩家的"出局成本" = 决定他敢不敢背叛的关键
  4. 找"承诺机制"——谁通过哪种方式锁死了自己的策略
  5. 重复博弈视角：单次理性 vs 重复理性的差异
- 适用领域：**地缘、监管博弈、标准之争、加密协议、商战**
- 应用 demo（USB-C 标准之争）：
  USB-C 不是技术最优解，而是**Schelling Point**——所有非 Apple 厂商都默认选它。Apple 抗了多年最终被欧盟监管 + 协调失败成本压垮。这是经典"焦点+承诺机制"博弈：欧盟立法把焦点变成了承诺。
- **不适用**：单方决策领域、纯艺术创作

---

### 13. 多元思维模型 · Latticework of Mental Models
- 来源：Charlie Munger
- 解决什么问题：**单学科分析有盲区，怎么用多学科交叉验证**
- 用在哪一层：**元方法（叠加在所有工具之上的"工具的工具"）**
- 怎么用：
  1. 任何领域问题至少用 3 个不同学科的模型独立分析
  2. 三个模型结论一致 → 高置信
  3. 三个模型结论冲突 → 找冲突的根源（哪个假设不一样）
  4. 反例：单一锤子综合症——心理学家用心理学解释一切
  5. 实操：心理学 + 经济学 + 物理学（涌现）+ 生物学（演化）+ 数学（概率）
- 适用领域：**所有领域**（特别是复杂系统、跨学科问题）
- 应用 demo（理解 Web3 退潮）：
  心理学（FOMO + 自我实现叙事）+ 经济学（博弈论 + 庞氏机制）+ 物理学（耗散结构 + 临界点）+ 历史（1849 加州淘金 + 1999 互联网泡沫）。**单用任何一个学科都解释不全**，三个一起才能解释"为什么明知是泡沫还有那么多聪明人参与"。
- **不适用**：紧急时间约束的单点决策（多学科分析慢，急的时候用主导学科）

---

### 14. 势 / 术 / 道（东方思维）
- 来源：先秦兵家、《孙子》《管子》传统
- 解决什么问题：**怎么把"时机/技巧/规律"分层看一个领域**
- 用在哪一层：**范式层（中文文化领域必用）**
- 怎么用：
  1. **道**：不变的底层规律（市场永远存在供需、人性永远有贪嗔痴）
  2. **术**：可学的技巧、方法、策略（具体打法）
  3. **势**：当下的时机、风口、势能方向（最快变化的部分）
  4. 三层都要看——只懂术的人是工匠，懂道的是哲学家，懂势的人赚短钱，**三层都懂的人赚长钱**
  5. 反向问：这个领域当下的"势"逆"道"吗？逆道之势必败
- 适用领域：**中国文化领域必用**、商战分析、投资、政策分析
- 应用 demo（直播电商）：
  道：人性需要被娱乐 + 信任 + 消费冲动，三者结合永不过时。术：选品 / 话术 / 流量分配 / 主播培养——可学。势：2018-2021 平台流量红利 + 监管空窗 + 渠道变革三浪叠加，2022 后势退。**只学术的主播在势退后大批阵亡，懂道的人转去做"信任经济"新形式**（私域 / 社群）。
- **不适用**：纯技术细节领域（势道术对一个 SQL 优化问题用不上）

---

### 15. 阴阳辩证
- 来源：《易经》《道德经》传统辩证法
- 解决什么问题：**任何力量到极致会反转，怎么识别"反转点"**
- 用在哪一层：**元透镜**
- 怎么用：
  1. 任何"过强"的力量找它的对立面在哪里悄悄壮大
  2. "反者道之动"——反转往往在"看起来最稳定"的时候启动
  3. 阴中有阳、阳中有阴：垄断里有它崩塌的种子，颠覆者里有它腐化的种子
  4. 关注"边界条件"——阴阳交界处张力最大、机会和风险都在那
  5. 警惕：辩证法滥用容易变成"什么都对"
- 适用领域：**中国文化领域**、宏观周期、政治经济学
- 应用 demo（互联网平台监管反转）：
  2010s "平台越大越好"是当时的阳，但阳到极致——数据垄断 + 二选一 + 大数据杀熟——把"反平台"的阴气养大了。2021 反垄断风暴的爆发不是偶然，**而是阳极生阴的必然**。当下的 AI 监管也在累积同样的阴。
- **不适用**：单点技术决策、短周期事件

### 必用刀的强制最低产出

每个领域类型下"必用刀"的硬产出标准（写作时不出现学者名，但 narrative_html 必须含对应关键词触发）：

- **技术领域必用 Wardley + Perez + Christensen + Taleb + Helmer + 网络效应分类（含零网络效应判断）**——前 4 个分别对应：演化象限 / 资本周期 / 颠覆机制 / 反脆弱评分；Helmer 7 Powers 拆玩家命门；网络效应分类要明确判断"是否存在数据/网络/规模 N² 边际价值"，零网络效应时 Helmer 表里两条直接砍废。**关键词触发**：演化象限 / genesis / commodity / 导入期 / 疯狂期 / 部署期 / 低端颠覆 / 反脆弱 / 杠铃 / 脆弱 / 网络效应。

- **商业领域必用 Porter + Helmer + Christensen + Wardley + Perez + 网络效应**——五力定结构上限、7 Powers 拆护城河、Christensen 看颠覆方向、Wardley 看演化、Perez 看大周期、网络效应判断"赢家通吃 vs 群雄割据"。**关键词触发**：议价能力 / 利润瓶颈 / 护城河 / 转换成本 / 演化象限 / 资本周期 / 网络效应。

- **金融领域必用 Porter + Soros + Taleb + Mauboussin + Braudel + Perez**——Porter 圈定 industry rents、反身性看叙事-资金回路、反脆弱看尾部暴露、二阶看共识反共识、Braudel 三尺度分清事件 / 周期 / 结构、Perez 给周期长度坐标。**关键词触发**：反身性 / 自我证实 / 尾部 / 长尾 / 反脆弱 / 共识 / 反共识 / 三尺度 / 长周期 / 资本周期。

- **文化领域必用 Braudel + Soros + Schelling + Munger + 东方思维**——文化的时间常数极长，Braudel 必用；叙事即现实，反身性必用；多方协调求焦点，Schelling 必用；Munger 多学科 + 东方"势/术/道"避免单线条解读。**关键词触发**：长时段 / 几个世纪 / 焦点 / 默认协调 / 道 / 术 / 势 / 多学科 / 反身性。

### 选刀流程（v0.3 强化）

```
┌─────────────────────────────────────────────────────────┐
│ Step 0  先问：这是哪一类领域？（技术 / 商业 / 金融 / 文化）  │
│ Step 1  锁定该列下所有 ✅ 必用刀（不是"挑几把"，是"全用"）│
│ Step 2  从 ⚪ 选用刀里再加 1-2 把贴合具体子领域的         │
│ Step 3  ❌ 不适刀直接跳过——硬用就是学究腔                 │
│ Step 4  写作时把刀的"思考方式"翻译成业务语言（去掉学者名）│
└─────────────────────────────────────────────────────────┘
```
