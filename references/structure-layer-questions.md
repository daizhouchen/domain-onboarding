# 结构层提问范式

> 结构层（structural layer）是四层里**最难写好**的一层。多数"领域分析"看似讲到了结构层，其实还停在机制层换个说法。本文给出 6 个必问的结构层问题，每个都给"到位标准"+ 正反例，帮你识别并跳出伪结构层。

## 一、为什么结构层最难写

结构层回答的是：**为什么这个领域必须长成这样，而不是别的样子？**

它不是"现在的格局是寡头"（这是机制层的现象描述），而是"在 X 约束下，这个领域必然会演化为寡头"（这是结构层的因果陈述）。

### 伪结构层 vs 真结构层

| 伪结构层（机制层换说法） | 真结构层 |
|---|---|
| "这个行业是网络效应主导的" | "在用户切换成本 ≈ 0 的领域，网络效应是唯一长期壁垒——所以新玩家进场必须先做单边补贴" |
| "头部公司有规模优势" | "固定成本占比 > 70% 的领域，单位经济只有在 X 量级以上才转正——这一条决定了每代头部公司不超过 3 家" |
| "AI 行业进入下半场" | "训练成本 / token 在过去 24 个月降了 N 倍，但推理成本下降速度落后训练成本——这一不对称决定了未来 5 年商业模式的形态" |

> 暗箭工具：**长时段（longue durée）思路 + 演化象限（创世/定制/产品/通用）**。判断一个事物是不是结构性的，看它跨越了多少个产品周期还在；判断一个领域演化到哪一象限，决定了竞争形态。

写结构层的纪律：**每一句结构层陈述，都要能写出"如果 X 不成立，这一陈述就不成立"的反事实条件**。写不出反事实条件的，是机制层装结构层。

## 二、6 个必问的结构层问题

### Q1. 这个领域的 reality-shaping 约束是什么？

**问题表述**：哪些物理 / 经济 / 制度上的硬约束，决定了所有玩家都必须在这个约束下设计自己的产品和商业模式？

**到位标准**：
- 必须是**可量化或可指认的具体约束**，不是抽象描述
- 必须解释当前格局：这个约束如果消失，格局会怎么变
- ≥3 条约束，并标记每条的"硬度"（不可变 / 短期不可变 / 长期可松动）

**正例**（数据中心运营领域）：
> "三大约束：①电力——全球数据中心已经成为电网平衡的边缘负载，新建项目接入时间从 12 个月变成 36–60 个月；②冷却水——液冷需求让选址向北纬高纬度迁移；③低延迟跨区——光速给出了硬上限，跨大西洋 RTT 不可能低于 56ms。这三条决定了'AI 数据中心选址'不是商业决策，是物理决策。"

**反例**（同领域，伪结构层）：
> "数据中心建设需要资金、技术和管理。"——这是机制层的废话，没有约束、没有不可变性、没有形态决定。

### Q2. 如果改变某一约束，这个领域的形态会怎么变？

**问题表述**：把 Q1 的约束依次松绑，会出现什么完全不同的领域形态？

**到位标准**：
- 至少回答 2 条"如果 X 松绑会怎样"
- 必须给出"形态变化"，不是"会更好 / 会更差"
- 给出"松绑的可能路径"——技术突破？监管？地缘？

**正例**（向量数据库领域）：
> "如果嵌入维度可以无损压缩到 1/100（量化突破）：当前 ANN 索引的存储瓶颈消失，独立向量数据库的存在理由削弱一半，会被通用 DB 完全吸收。如果上下文窗口扩展到亿级 token 且推理成本可控：检索环节本身被'整段塞进 prompt'替代，向量数据库这个品类可能从工程必需品退化为优化工具。"

**反例**：
> "如果技术继续发展，向量数据库会更好用。"——没有约束、没有形态变化。

### Q3. 哪些"表面变化"是结构性的？哪些只是周期波动？

**问题表述**：观察到的最近一年的变化里，哪些是真的改变了领域形态，哪些只是周期内的波峰波谷？

**到位标准**：
- 必须给出"周期性 vs 结构性"的判别**判据**，不是结论
- 至少举 2 个"看起来像结构变化但其实是周期"的反例
- 至少举 1 个"看起来不起眼但其实是结构性"的正例

> 暗箭工具：**短时段事件 / 中时段周期 / 长时段结构**——三分时间尺度的训练。判断一件事在哪一格，看它跨越的时间常数。

**正例**（SaaS 领域）：
> "结构性：净留存（NDR）从 130%+ 退到 110% 是结构性——它反映了客户预算审视周期的变化，不是某一季度的销售节奏。周期性：单季 ARR 增长率波动 ±20% 是周期性——和宏观资本支出周期同频。容易看错的：'AI Agent 替代 SaaS' 喊了三年但 SaaS 软件支出没掉——属于'看起来结构性其实周期性叙事'。"

**反例**：
> "今年 SaaS 不太好。"——没有结构 vs 周期的判别。

### Q4. 这个领域的"不可变"在哪？

**问题表述**：在所有看似剧变的现象之下，哪些东西**几十年都没变也不会变**？

**到位标准**：
- 必须给出"为什么这一条不可变"的物理 / 经济 / 心理基础
- ≥2 条不可变项
- 不可变项必须是**领域特有**的，不是"人性"这种通用废话

**正例**（消费内容领域）：
> "①注意力是零和的：人均日醒着时间 16 小时不会变，每个新平台的崛起都是从其他平台抢时间。②内容生产边际成本趋零，但分发与排序仍是稀缺资源。这两条从报纸时代到 TikTok 时代没变。"

**反例**：
> "用户喜欢好内容。"——是真理但不是结构层不可变项。

### Q5. 为什么这个领域必须存在？

**问题表述**：这个领域满足了什么需求？如果它不存在，这个需求会以什么形态被满足？

**到位标准**：
- 给出"需求-供给"的因果链，不止于"用户需要 X"
- 回答"它不存在会怎样"——是被替代，还是需求消失
- 给出"它在历史上以什么形态出现过"——历史前身（precursor）

**正例**（REITs 领域）：
> "REITs 必须存在的根本原因：商业地产是高资本密度、低换手、长周期资产，传统融资形态（银行贷款 + 私募股权）让中小投资者无法参与。REITs 把不动产证券化，让股票二级市场流动性嫁接到不动产上。如果 REITs 不存在，这个需求一部分流向地产开发商上市公司（间接持有），一部分流向不动产基金（机构独享）——但二级市场流动性 + 散户可参与这两条在没有 REITs 的国家里几乎无法兼得。"

**反例**：
> "REITs 让人投资不动产更方便。"——没有因果、没有反事实。

### Q6. 为什么这个领域必须长成这样而不是别的样子？

**问题表述**：在所有可能的产业组织形态里，为什么偏偏演化出了现在这种？换一个时代、换一个国家，会不会长成完全不同的样子？

**到位标准**：
- 必须给出"路径依赖（path dependence）"的关键节点
- 至少一个"反事实"——如果 X 节点选了 Y，会变成什么
- 不能只用"市场选择了它"——市场是结果不是原因

> 暗箭工具：**演化象限**——从创世（Genesis）到定制（Custom）到产品（Product）到通用（Commodity）。每个领域在演化轴上的位置决定了竞争形态。

**正例**（日本动画产业）：
> "日本动画为什么是制作委员会制 + 制作公司零库存 + 声优偶像化？路径依赖：①1960 年代手冢治虫低价接电视台订单（《铁臂阿童木》），把单集制作费打到不可能赚钱的水平，为了存活必须靠周边和版权分成——这一节点决定了产业链利润分布；②1990 年代制作委员会制度成型，分散投资风险但也分散了制作公司话语权；③声优经纪与偶像产业绑定。换成美国动画产业（迪士尼自持 IP + 大制作 + 院线驱动），是另一条完全不同的路径，源头是 1937 年《白雪公主》而不是 1963 年《铁臂阿童木》。"

**反例**：
> "日本动画就是这么发展的。"——是叙述不是解释，没有路径依赖、没有反事实。

## 三、写作纪律检查表

写完结构层之后，自检：

- [ ] 每一条结构层陈述是不是都能写出反事实条件？
- [ ] reality-shaping 约束是不是具体可指认（≥3 条，标硬度）？
- [ ] 是不是给出了"周期 vs 结构"的判别判据？
- [ ] 不可变项是不是领域特有，不是通用废话？
- [ ] 形态决定论是不是有路径依赖支撑，不是"市场选择"？
- [ ] 没有把"行业格局是 X" 当成结构层（那只是现象层归纳）？

## 四、结构层与机制层的边界

写作时一个实用的判别：

```
┌────────────────────────────────────────────┐
│ 把陈述去掉时间状语，还成立吗？               │
│  · 成立 → 结构层（如：固定成本占比 > 70%）   │
│  · 不成立 → 机制层（如：今年净留存掉到 110%）│
└────────────────────────────────────────────┘
```

结构层陈述应该跨越多个机制层周期还成立。如果它会随季度变动，那它就在机制层。
