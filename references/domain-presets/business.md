# 商业领域 Preset · Business Domain

> 本 preset 用于"看商业模式、看单元经济、看产业链"的领域。例：SaaS / 跨境电商 / 直播带货 / 共享经济 / 订阅经济 / B2B 平台 / 招聘行业 / 教育培训 / 餐饮连锁 / 零售 / 物流 / 出海。

商业领域和技术领域最大的不同是：**没有 ground truth benchmark**——同一个 GMV 数字，扣不扣退货、含不含税、按下单还是按签收口径，能差 30%。所以商业领域的骨架重点不是"对错"，是**"谁的视角"**——卖方的故事、买方的故事、监管的故事、媒体的故事，永远不一样。

> 入门一个商业领域，**先找到三件事**：(1) 这领域怎么赚钱（unit economics 一句话讲清楚）；(2) 这领域上一轮"模式拐点"是什么——直营变平台？平台变 SaaS？SaaS 变 PLG？(3) 这领域的"叙事冠军 vs 数据冠军"是不是同一家——舆论吹的和报表赚的是不是一回事。

## 骨架五件套 · 商业领域适配

### 1. 核心概念图（Concept Map）

商业领域的概念图必须分**三块**：商业模式、关键指标、市场分层。

```
┌─────────────────────────────────────────────────────┐
│ 商业模式  谁付钱 / 付什么钱 / 通过谁付 / 多久付一次 │
├─────────────────────────────────────────────────────┤
│ 关键指标  LTV · CAC · Churn · ACV · NDR · GMV ...   │
├─────────────────────────────────────────────────────┤
│ 市场分层  头部 / 腰部 / 长尾 / 利基                 │
└─────────────────────────────────────────────────────┘
```

强制内容清单：

- [ ] 商业模式画布六格（客户 / 价值 / 渠道 / 关系 / 收入 / 成本）至少填满四格
- [ ] 6-10 个关键指标，每个含**行业基准值**（不是定义，是数）
- [ ] 市场分层每一档至少 2 家公司、营收量级
- [ ] 必含"中国/海外两套数据"如果是出海领域

**反例**：

> "SaaS 的核心指标是 ARR、Churn、NDR。"

这是教材。"NDR > 120% 是优秀"才是 preset 该写的——配上"Snowflake 158% / Atlassian 124% / 普通 SaaS 105%"。

**正例**（关键指标行业基准）：

| 指标 | 计算 | 优秀 | 及格 | 危险 |
|------|------|:----:|:----:|:----:|
| NDR | 老客户期末 / 期初 | >120% | 100-120% | <100% |
| LTV/CAC | 客户终身价值 / 获客成本 | >3 | 2-3 | <1.5 |
| Magic Number | 新增 ARR / S&M 投入 | >1 | 0.5-1 | <0.5 |

### 4. 矛盾结构（Tensions）

商业领域的核心矛盾通常落在四组对立轴上：

| 矛盾轴 | A 极 | B 极 | 撕裂点 |
|--------|------|------|--------|
| 渠道形态 | 直营 | 平台 | 控制力 vs 规模天花板 |
| 增长路径 | 烧钱扩张 | 单元经济正 | 资本周期 vs 现金流 |
| 客户分布 | 头部少量大单 | 长尾海量小单 | LTV vs CAC 结构 |
| 玩家段位 | 巨头 | 创业 | 渠道 / 流量 / 牌照 vs 灵活度 |

强制内容清单：

- [ ] 至少 3 组矛盾，每组给 ≥2 个事实锚点
- [ ] 每组矛盾标"当前局势"
- [ ] 标"利益相关方真实诉求"——员工 / 创始人 / 投资人 / 监管 / 用户各想要什么（往往冲突）

## 推荐分析工具（来自 analytical-toolbox.md）

商业领域**默认调用**这四件套，但写正文时**不要念框架名**：

### Porter 五力

供方议价、买方议价、潜在进入者、替代品、行业内竞争。**用法**：用来诊断"为什么这个行业利润率低/高"。如果五力里有四力都强，行业利润必然薄——这时商业模式的所有动作都是在"绕开五力"。

### Helmer 7 Powers

规模经济、网络效应、反向定位、转换成本、品牌、垄断资源、流程效能。**用法**：用来判断"这家公司护城河是真还是假"。一家公司必须至少占 1 条 power 才有长期 alpha——只占"品牌"或"流程效能"的，通常会被新一代玩家替换掉。

### 网络效应分类

直接（同侧用户互相加值）/ 间接（双边平台）/ 数据（用得越多模型越准）/ 社交（朋友都在）。**用法**：很多公司号称"有网络效应"——逐条对照实际是哪一种、强度多大。SaaS 公司常常根本没有网络效应，只有转换成本。

### 双边平台理论

谁补贴谁、who's the money side / who's the subsidy side。**用法**：滴滴补贴司机还是乘客？淘宝补贴卖家还是买家？补贴方向决定了后期定价权倾斜方向。

## 完整 Preset 应用 Demo · 跨境电商

### 商业模式三层填充

```
商业模式  │ 中国卖家 → 跨境平台 → 海外消费者
          │ 收入：商品差价 + 平台抽佣 + 物流加价 + 广告
          │ 付费链路：消费者 → 平台 → 卖家（T+15-30）
关键指标  │ ROI（广告投放回报）/ 退货率 / FBA 库存周转
          │ 跨境时效（dock-to-door）/ 海外仓占比
市场分层  │ 头部：Amazon / Shein / Temu / TikTok Shop
          │ 腰部：阿里国际站 / SHEIN 第三方 / Lazada
          │ 长尾：独立站（Shopify 上 100 万+ 中国卖家）
```

### 关键指标行业基准

| 指标 | 优秀 | 及格 | 危险 | 备注 |
|------|:----:|:----:|:----:|------|
| 退货率 | <8% | 10-15% | >20% | 服饰类是重灾区 |
| 广告 ACoS | <15% | 15-25% | >30% | Amazon 站内广告占比 |
| FBA 库存周转 | >12次/年 | 6-12次 | <6次 | 慢周转直接吃利润 |
| 毛利率 | >45% | 30-45% | <25% | 不含广告 |

### 玩家地图（举头部）

| 玩家 | GMV / 营收 | 估值 / 市值 | 一句话定位 |
|------|------------|-------------|------------|
| Amazon 跨境 | 全球 GMV >$700B | 公开市值约 $2T | 第三方卖家贡献过半 |
| Shein | 2023 GMV ~$45B | 估值 660 亿（2023）| 柔性供应链 + 数据驱动选品 |
| Temu | 2023 GMV ~$15B | 拼多多旗下 | 全托管模式 + 极致补贴 |

### 矛盾结构（举两组）

**矛盾 1：直营品牌 vs 全托管平台**

- 事实锚点 1：Anker 2023 营收 $2.4B、毛利率 43%（A 级源：财报）
- 事实锚点 2：Temu 2023 GMV $15B、补贴损失估算超 30 亿美金（B 级源：The Information）
- 事实锚点 3：Shein 全托管模式上线后第三方卖家占比从 0 升至 ~40%（B 级源：媒体报道）
- **当前局势**：全托管在 2023-2024 起势，但单元经济存疑
- **未解之谜**：当 Temu 停止补贴后，平台模式还活不活得下来

**矛盾 2：流量获客 vs 单元经济**

- 事实锚点 1：Temu 2023 单 CPA 一度超 $40（B 级源）
- 事实锚点 2：跨境包裹平均客单价 $20-30
- 事实锚点 3：拼多多港股 2024 季报显示海外业务仍亏损
- **当前局势**：典型的 LTV/CAC 失衡——靠资本输血

### 单元经济拆解（举 Temu 一单）

```
客单价                $20.00
  – 商品成本（采购）  ($8.00)   40%
  – 物流（小包）      ($4.00)   20%
  – 平台运营 / 分摊   ($2.00)   10%
  – 关税 / 增值税     ($0.50)   2.5%
  ──────────────────
  毛利                 $5.50    27.5%
  – 获客成本（高峰期）($8.00)   40%
  ──────────────────
  贡献利润            (-$2.50)  -12.5%
  × 复购系数（估）    × 2-3
  ──────────────────
  6 个月 LTV           $11-16   依赖复购拉回
```

**关键问题**：单笔贡献利润为负 → 唯一出路是把复购拉到 ≥3 次 + CAC 降到 $4 以下。

## 自反性警告（商业领域专属）

商业领域最容易踩三个坑：

1. **GMV 崇拜**：媒体爱写大数字，但 GMV 和实际收入差 5-10 倍是常态。**永远换算成 net revenue 再比较**。

2. **创始人故事陷阱**：被报道的故事永远是 survivorship bias。每个被吹的"颠覆者"背后有 50 家死掉的——只看活下来的得不出商业规律。

3. **时间冻结陷阱**：商业领域 6 个月就能换天——AI 训练数据 cutoff 后的事**全部按"我不掌握"处理**，不要凭逻辑外推。例：Temu 2024 之后单元经济变化、TikTok 美国禁令进展，AI cutoff 后一概不知道，写"我不掌握 + 用户去验证"比硬猜值钱。
