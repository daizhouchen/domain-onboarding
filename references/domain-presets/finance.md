# 金融领域 Preset · Finance Domain

> 本 preset 用于"看监管、看周期、看风险"的领域。例：REITs / 对冲基金 / 私募股权（PE / VC）/ 加密货币 / 大宗商品 / 量化交易 / ETF / 衍生品 / 央行政策 / 高收益债 / 不良资产（NPL）/ 资产证券化（ABS / MBS）。

金融领域和技术 / 商业领域最大的不同是：**反身性最强**——价格本身会反过来改变基本面（Soros 反身性）；**黑天鹅最致命**——99% 的时间风平浪静，1% 的时间所有模型同时失效。所以金融领域的骨架必须**反复打自己的脸**——任何"这次不一样"的判断都要标"上次有人这么说，结果是 X"。

> 入门一个金融领域，**先找到三件事**：(1) 这领域上一次"系统性事件"（崩溃 / 监管重塑 / 范式切换）是哪一年、发生了什么；(2) 当前周期处于"狂热 / 冷静 / 恐慌 / 复苏"的哪一段——以及谁在押注转折；(3) 监管者最近半年在写什么——监管文件比新闻更早预告变化。

## 骨架五件套 · 金融领域适配

### 1. 核心概念图（Concept Map）

金融领域的概念图必须**五要素并列**：标的、风险、回报、流动性、监管。

```
┌─────────────────────────────────────────────────────┐
│ 标的     什么资产、什么合约、谁发行                 │
│ 风险     利率 / 信用 / 流动性 / 操作 / 政策风险      │
│ 回报     yield / cap rate / IRR / sharpe / alpha    │
│ 流动性   T+0 / T+1 / 锁定期 / 二级市场厚度          │
│ 监管     谁监管、什么牌照、最新政策口径              │
└─────────────────────────────────────────────────────┘
```

强制内容清单：

- [ ] 标的：定义 + 至少 3 个真实代码 / 名称 + 代表案例
- [ ] 风险：每一类含历史最大回撤 + 触发条件
- [ ] 回报：含**长期均值** + **历史区间**（不要只给单点估值）
- [ ] 流动性：分一级 / 二级 / 私募市场，三档分别说
- [ ] 监管：发文机关 + 文号 + 生效日 + 实操影响

**反例**：

> "REITs 是把不动产打包成可交易证券。"

这是教材。**正例**：

> 美国 REITs 由 1960 年《房地产投资信托法案》创设，**强制条件**：90% 应税收入分红、75% 资产是不动产、≥100 个股东。**潜台词**：这个 90% 分红条款决定了 REITs **天然是利率敏感品**——分红率必须高于无风险利率才有意义，所以加息周期里所有 REITs 同时受压。

### 2. 玩家地图（Player Map）

金融领域的玩家分**五象限**：

```
                    监管者
                       │
         评级机构 ── 中央 ── 媒体 / 信息商
                       │
       买方 ────────  市场  ──────── 卖方
   （asset side）              （liability side）
                       │
                   经纪商 / 通道
```

强制内容清单：

| 类别 | 例 | 数量要求 |
|------|----|----:|
| 买方 | 共同基金 / 对冲基金 / 主权财富 / 养老金 / 散户 | ≥4 |
| 卖方 | 投行承销 / 发行人 / 做市商 | ≥3 |
| 经纪商 / 通道 | Prime broker / 交易所 / 清算所 | ≥2 |
| 监管者 | 央行 / 证监会 / 银保监会 / SEC / FED | ≥2 |
| 评级机构 | Moody's / S&P / Fitch / 中诚信 | ≥2 |
| 信息商 / 媒体 | Bloomberg / Reuters / 万得 / 路透社 | ≥2 |

**关键问题**：每一类玩家**真实诉求是什么**？买方求收益、卖方求佣金、监管求稳定、评级求声誉、媒体求流量——这些诉求经常冲突。

### 4. 矛盾结构（Tensions）

金融领域的核心矛盾通常落在四组对立轴上：

| 矛盾轴 | A 极 | B 极 | 撕裂点 |
|--------|------|------|--------|
| 收益来源 | alpha（择时择股）| beta（赚 beta）| 后视镜 vs 前瞻、能力 vs 运气 |
| 管理风格 | 主动 | 被动 | fee 高但跑输 vs fee 低但永远平均 |
| 创新 vs 稳定 | 创新（杠杆 / 衍生品）| 监管（穿透 / 限额）| 系统性风险 vs 资本效率 |
| 参与者 | 散户 | 机构 | 信息差、工具差、税收待遇差 |

强制内容清单：

- [ ] 至少 3 组矛盾，每组给 ≥2 个事实锚点
- [ ] 每组矛盾标"上一轮谁赢了、为什么"
- [ ] 每组矛盾标"反身性触发条件"——什么情况下输赢会反转

## 推荐分析工具（来自 analytical-toolbox.md）

金融领域**必用**这三件套——尤其反身性，**金融领域的核心透镜**。

### Soros 反身性（金融领域必用 ⭐）

价格 ↔ 基本面互相影响、共同演化。**用法**：识别"自我证实回路"和"自我崩溃回路"。

- **自我证实**：股价涨 → 公司容易融资 → 业绩改善 → 股价继续涨。直到资本市场口味变化。
- **自我崩溃**：高杠杆资产价格跌 → 强平 → 更多供给 → 价格继续跌 → 更多强平。

每个金融领域 preset 必须找出至少 1 条自我证实链和 1 条自我崩溃链。

### Taleb 黑天鹅 / 反脆弱

- **黑天鹅**：罕见、影响巨大、事后看似可预测。
- **反脆弱**：在波动中受益的系统结构（凸性敞口）。

**用法**：列出领域内的"已知的未知"——不是预测下一个黑天鹅，是**列出"如果发生 X，整个领域重画"的 X 清单**。例：REITs 领域的"如果 10Y 国债收益率 > 6% 持续 2 年"。

### Mauboussin 二阶思维

一阶思维：A 涨 → 我跟着买。二阶思维：所有人都看到 A 涨 → 拥挤交易 → 反向布局 / 离场。**用法**：识别"过度共识"——当某个观点在卖方研报里出现 80% 频率时，往往就是反指。

## 必含特殊章节

### A. 风险拆解（Risk Decomposition）

```
总风险
├── 市场风险（systematic）
│   ├── 利率风险
│   ├── 汇率风险
│   └── 大盘 beta
├── 信用风险（credit）
│   ├── 违约概率
│   └── 违约损失率
├── 流动性风险
│   ├── 资产端流动性
│   └── 负债端流动性（赎回压力）
├── 操作风险
│   └── 系统、合规、人为失误
└── 政策 / 法律风险
    └── 监管口径变化
```

每一类必须给：**历史最大回撤** + **触发条件** + **对冲工具**。

### B. 历史周期对照（Cycle Mapping）

把当前周期套到历史周期上——美国 REITs 1990 / 2007 / 2020 三次周期顶部分别有什么共性？2024 年的指标读数和哪一次最像？给"相似度评分"+"反例"。

### C. 监管时间轴

金融领域几乎全部由监管定义。**强制画近 30 年的监管节点**（远超商业领域的 5-10 年）：

```
1980  美国 ERISA 修正 → 养老金可投另类资产 → PE 行业崛起
1999  Gramm-Leach-Bliley → 商业银行 + 投行混业
2010  Dodd-Frank → Volcker rule、CFPB 设立
2018  欧盟 MiFID II → 研究付费透明化
2023  美国硅谷银行倒闭 → 中型银行流动性新规讨论
2024  巴塞尔 III "终局"实施延期 ......
```

### D. 黑天鹅清单（Known Unknowns）

至少列 5 条**情景式假设**：

```
[ ] 如果 X 发生，触发条件是 ___，传染路径会是 ___，对冲工具是 ___
```

例：

> 如果美国商业地产空置率持续 ≥20% 超过 18 个月，触发条件是 WFH 永久化 + 大宗融资到期墙叠加，传染路径是中型银行 CRE loan 减值 → 区域银行流动性危机 → 美联储被迫先降息后加监管，对冲工具是 CRE CDS / 区域银行做空 / 长久期国债。

## 完整 Preset 应用 Demo · REITs

### 五要素填充

```
标的    │ 美国上市 REITs（约 200 只）+ 私募 REITs + 中国公募 REITs
        │ 代码举例：VNQ（先锋 ETF）/ O（Realty Income）/ AMT（American Tower）
        │ 中国：华夏越秀 / 中金普洛斯 / 中航首钢绿能等首批 9 只（2021）
风险    │ 利率风险（最致命）/ 资产质量风险 / 流动性风险（私募 REITs）
回报    │ 美国 REITs 长期年化总回报 ~10%（含分红，1972-2023 NAREIT 数据 A 级）
        │ 中国公募 REITs 上市以来年化 -5% 至 +15% 不等（cutoff 2024 数据 B 级）
流动性  │ 公募 REITs：交易所 T+0 / T+1
        │ 私募 REITs（Blackstone BREIT 等）：每月赎回有上限（关键限制）
监管    │ 美国：1960 REIT Act + IRC § 856（90% 分红条款）
        │ 中国：证监会 + 发改委 双口径，2020 年 1058 号文起步
```

### 玩家地图（举头部）

| 类别 | 玩家 | 一句话定位 |
|------|------|------------|
| 美国上市 | American Tower（AMT）| 全球最大通信塔 REIT，2023 市值 $900 亿 |
| 美国上市 | Realty Income（O）| 月度分红"圣诞老人"、零售物业 |
| 美国私募 | Blackstone BREIT | 2022-2023 赎回潮的主角、私募 REITs 代表 |
| 中国公募 | 中金普洛斯 | 物流仓储 REIT、首批 9 只之一 |
| 监管 | NAREIT（行业协会）| 数据 + 游说，非政府机构 |

### 时间轴（含三周期 + 三黑天鹅 + 三监管）

```
周期 1  1990-2000  储贷危机后房地产复苏 → REIT 现代化法案（1986 + 1999）
周期 2  2003-2007  金融危机前商业地产泡沫 → 2007-2009 美国 REITs 跌幅 -68%
周期 3  2020-2024  零利率 → 加息 → 商业地产承压 → 2024 仍在出清

黑天鹅 1  2008 雷曼倒闭：REITs ETF VNQ 单年 -38%
黑天鹅 2  2020 COVID：办公 REITs 跌 -50%、酒店 REITs 跌 -60%
黑天鹅 3  2022-2023 Blackstone BREIT 赎回潮：每月赎回上限触发

监管 1   1960 REIT Act → 创立品类
监管 2   1986 Tax Reform → 限制 PE 滥用 REIT 结构
监管 3   2020 中国 1058 号文 → 公募 REITs 试点
```

### 矛盾结构（举两组）

**矛盾 1：公募流动性 vs 私募收益**

- 事实锚点 1：BREIT 2022-2023 净赎回超 $90 亿（A 级源：Blackstone 财报）
- 事实锚点 2：同期公募 REITs ETF VNQ 跌幅 -25%（A 级源：交易所数据）
- 事实锚点 3：BREIT 自报 NAV 仍正回报，但二级市场对私募 NAV 估值打折 20-30%
- **当前局势**：流动性溢价从"奢侈品"变成"刚需"，私募 REITs 模式遭遇大考
- **反身性触发**：如果赎回潮恢复，BREIT 的 mark-to-model 估值方法学会被监管重审

**矛盾 2：商业地产 vs 远程办公（结构性对赌）**

- 事实锚点 1：美国一线城市办公空置率 2024 普遍 18-22%（B 级源：CBRE / Cushman 数据）
- 事实锚点 2：办公 REITs 板块 2020-2024 累计跌 -50%
- 事实锚点 3：旧金山部分办公楼成交价跌至 2019 年的 30-40%
- **当前局势**：办公地产已 price in 大部分坏消息，但融资到期墙（2024-2026）尚未释放
- **反身性触发**：如果中型银行因 CRE loan 减值流动性危机 → 监管收紧 → CRE 再次重定价

### 风险拆解（举利率风险）

```
利率风险（REITs 最敏感）
├── 历史最大回撤：1994 美联储加息周期 -8%（单年）/ 2022 加息周期 -25%
├── 触发条件：10Y 国债收益率 > REIT 分红率 + 200bp
├── 对冲工具：长久期国债空头 / SPDR Sector ETF
└── 反身性陷阱：加息 → 估值跌 → 再融资难 → 强卖资产 → 估值再跌
```

### 黑天鹅清单（举 3 条）

```
[ ] 商业地产再融资墙（2024-2026 美国 CRE 到期 ~$1.5T）
    传染路径：到期违约 → 区域银行减值 → 流动性收紧 → REITs 再融资成本飙
    对冲：CRE CDX 空头 / 长久期国债多头

[ ] 远程办公永久化（>50% 白领长期混合办公）
    传染路径：办公 REITs 永久减值 → 板块再分类 → 通用 REIT ETF 被动减仓
    对冲：办公 REIT 直接做空 / 长租公寓 REIT 多头

[ ] 中国公募 REITs 试点失败（破净潮 + 资金面持续负反馈）
    传染路径：发改委暂缓审批 → 已发产品流动性枯竭 → 影响保险 / 养老金配置
    对冲：尚无成熟工具
```

## 自反性警告（金融领域专属）

金融领域最容易踩四个坑：

1. **后视镜偏差**：每次崩盘后都觉得"早该看出来"——但当时所有人都在买。**强制规则**：任何"我看出来了"的判断必须配"为什么 90% 的专业玩家没看出来"。

2. **历史相似度陷阱**：把当前周期硬套到 1929 / 1987 / 2008 上。**强制规则**：相似度评分 + 至少 3 条反例（这次和那次的本质差异）。

3. **专家共识反指**：当卖方研报 80% 看多时往往是顶。AI 训练数据里卖方语言极重——**写金融 preset 时要刻意打折扣**。

4. **未来不可知**：金融领域比任何领域更"事后诸葛亮"。AI 对未来 6 个月的判断**全部按"我不知道"处理**——给情景而不给预测。预测是 D 级源，情景拆解是 A 级方法论。
