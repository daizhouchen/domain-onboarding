# 文化 / 社会领域 Preset · Culture & Society Domain

> 本 preset 用于"看创作者、看代际、看圈层"的领域。例：日本动画产业 / 播客生态 / 中国独立游戏 / 短视频文化 / 电竞 / 同人圈 / B 站二次元 / 街头文化 / 嘻哈 / 公路骑行 / 户外圈 / 民谣 / Vinted 二手 / 露营经济 / 黑神话玩家圈。

文化 / 社会领域和技术 / 商业 / 金融领域最大的不同是：**没有客观真理**——同一个文化现象在圈内人和圈外人眼里完全是两件事；**代际撕裂**——上一代 dominant 的标准下一代视为耻辱；**灰色地带巨大**——很多事**法律没定义、监管没表态、行业自律自我维持**，一个文件下来就重画。所以文化领域的骨架要**承认主观性**，但**用经济结构 + 代际地图**给主观一个坐标系。

> 入门一个文化领域，**先找到三件事**：(1) 谁付钱 / 谁创作 / 谁消费——这三方常常是不同的人，钱怎么从消费者流到创作者；(2) 这领域的代际分线是哪一年——之前的"老一代"和之后的"新一代"在审美、价值观、商业方式上有什么撕裂；(3) 这领域**圈外人最容易误解的一件事**是什么——这个误解暴露了整个领域的真实运作逻辑。

## 骨架五件套 · 文化领域适配

### 1. 核心概念图（Concept Map）

文化领域的概念图必须**四要素并列**：核心创作者、经济结构、文化代际、流派。

```
┌─────────────────────────────────────────────────────┐
│ 核心创作者  谁是 OG / 谁是当红 / 谁是新锐           │
│             创作者怎么定义自己（黑话、行规）         │
├─────────────────────────────────────────────────────┤
│ 经济结构    谁付钱、付多少、通过谁付（产业链）       │
├─────────────────────────────────────────────────────┤
│ 文化代际    1970s / 80s / 90s / 00s / 10s 的分代    │
│             每一代的代表作 + 价值取向                │
├─────────────────────────────────────────────────────┤
│ 流派        子流派、原教旨派、商业派、实验派        │
└─────────────────────────────────────────────────────┘
```

强制内容清单：

- [ ] 创作者：3 档（OG / 当红 / 新锐）各 ≥3 人，含最被记住的代表作
- [ ] 经济结构：钱的流向画出来——消费者 → 平台 → 中介 → 创作者，每一环抽多少
- [ ] 代际：至少 3 代，每代标"分代事件 / 标志作"
- [ ] 流派：至少 3 派，含"圈内黑话叫法"和"通俗叫法"

**反例**：

> "日本动画产业由制作公司、配音、播放平台等组成。"

这是百科。**正例**（经济结构）：

> 一部 TV 动画（12 话）制作预算 3-5 亿日元，**制作委员会**（投资方联合体）出资。播放费仅占成本回收 20-30%，真正赚钱的是**衍生品 + BD/DVD + 海外授权 + 演唱会**——所以剧本会自动倾向"能卖周边的角色"。**潜台词**：你看到的"画面崩坏"不是制作公司不努力，是**制作委员会预算分配**到这一话的钱不够。

## 推荐分析工具（来自 analytical-toolbox.md）

文化领域**默认调用**这三件套——单一框架在文化领域永远失效，必须多元。

### Munger 多元思维（社会现象不能单维度 ⭐）

文化现象不能只用经济学解释——要叠加心理学、社会学、人类学。**用法**：每个文化现象至少用 3 个不同学科的视角去看一遍。例：日本动画衰退？经济视角是制作委员会模式僵化、心理学视角是少子化与御宅族老化、人类学视角是亚文化的全球化稀释。

### Schelling Point（文化共识机制）

人们如何在没有沟通的情况下达成共识。**用法**：识别"圈子是怎么自我组织的"——为什么所有人都知道某个梗是底线、某个词是禁区？这些是 Schelling Point。圈子的边界往往就是 Schelling Point 的边界。

### 阴阳辩证（中国文化领域必用）

二元对立但又互相转化。**用法**：识别"看似对立、实则互为前提"的现象。例：中国独立游戏的"叛逆 = 主流"——所有标榜独立的工作室最后都变成商业明星，所有商业大厂都开始资助独立项目；分线消失，因为定义本身在阴阳转换。

### 矛盾结构（举两组）

**矛盾 1：商业化（鬼灭模式）vs 创作纯粹（吉卜力模式）**

- 事实锚点 1：鬼灭之刃 2020 票房 400+ 亿日元（A 级源：东宝财报）
- 事实锚点 2：吉卜力 2014 解散制作部、2017 重组（B 级源：媒体报道）
- 事实锚点 3：MAPPA 制作《咒术回战》员工劳动时长引发持续抗议
- **当前局势**：商业派在票房和影响力上完胜，但行业可持续性争议
- **圈外解读**：鬼灭很厉害；**圈内解读**：鬼灭是工业化巅峰，但代价是动画师工资 30 年没涨

**矛盾 2：全球化（Netflix）vs 本土性（深夜档原教旨）**

- 事实锚点 1：Netflix 2023 在日本动画投资约 1500 亿日元（B 级源）
- 事实锚点 2：深夜档作品全球流媒体首播比例从 2017 ~10% 升至 2023 ~50%
- 事实锚点 3：海外营收占日本动画总产值从 2010 ~20% 升至 2022 ~50%（A 级源：AJA 白皮书）
- **当前局势**：海外营收已超国内，**反身性**：剧情开始向"全球可读"调校（直接影响审美）

## 自反性警告（文化领域专属）

文化领域最容易踩四个坑：

1. **圈外视角伪装圈内**：AI 训练数据里关于亚文化的内容多数来自圈外 / 大众媒体的二手解读。**写文化 preset 时要刻意去找圈内的一手发声**——论坛帖子、creator 自己的访谈、圈内杂志，而不是 Wikipedia + 大众媒体。

2. **文化挪用陷阱**：把一个圈子的黑话用错了、用浅了，圈内人一秒识破。**不确定的黑话宁可不用**，或者明确标"我对此可能理解有误，请圈内人指正"。

3. **代际偏见**：AI 默认接受"老一代是经典 / 新一代是堕落"叙事——这是任何文化领域的老人话语权偏差。**强制规则**：每代都至少给一条"被时代低估的好作品"和一条"被时代高估的烂作品"。

4. **政治正确陷阱**：文化领域涉及性别 / 民族 / 阶层议题极多——AI 默认的 PC 框架往往和圈内真实文化逻辑冲突。**写时直接陈述事实和观点，标"这是 cutoff 时点的圈内主流看法、可能与外部 PC 立场冲突"**——比假装中立更诚实。
