## Q1. 颗粒度

### 超广（必须 push back）

**判别标准**（任一命中即超广）：

- 一个词能涵盖 ≥3 个独立成熟产业
- 维基百科的同名词条 >5 万字
- 行业内自己都不会用这个词指代具体工作（"我做 AI"是简历词，"我做大模型推理优化"才是工作词）

**典型超广领域**：

```
"AI" / "金融" / "互联网" / "新能源" / "医疗" / "教育" / "区块链" / "Web3"
```

**push back 模板**（拒绝写超广领域时的话术）：

> "XX 太广了。同一个词下面有 N 个独立产业，每个都值得单独 60 分钟。建议你选一个具体子领域：
>
> (a) 子领域 A — 一句话定位 — 适合什么背景的人
> (b) 子领域 B — 一句话定位 — 适合什么背景的人
> (c) 子领域 C — 一句话定位 — 适合什么背景的人
> (d) 子领域 D — 一句话定位 — 适合什么背景的人
>
> 或者如果你现在就想要"AI 大地图鸟瞰"——那不是这个 skill 的任务，建议你直接 Google 或者读一篇 State of AI Report。"

例（用户说"想了解 AI"）：

```
建议子领域：
(a) 大模型基础设施 — Anthropic/OpenAI/推理框架/GPU 调度 — 适合工程背景
(b) AI 应用层 — 编程助手/客服/写作/RAG — 适合产品/创业背景
(c) 具身智能 — 机器人/世界模型/VLA — 适合机器人/CV 背景
(d) AI 监管与伦理 — EU AI Act/红队/对齐 — 适合政策/法律背景
(e) AI 芯片 — Nvidia/Cerebras/光芯片 — 适合硬件背景
```

### 中等（正常进入）

**判别标准**（全部命中）：

- 圈内有公认的边界
- 玩家数量 30~300 量级（少于 30 太窄，多于 300 太广）
- 一个 60 分钟的报告能装下骨架五件套

**典型**：

```
向量数据库 / REITs / 日本动画产业 / 具身智能 / 黑莓生态 / 量化对冲基金 /
独立游戏发行 / Substack 创作者经济 / 围棋 AI / 中老铁路沿线物流
```

### 超窄（建议改用 prism-research 或 book-distiller）

**判别标准**（任一命中）：

- 是一个具体算法/产品/公司/书
- 玩家数量 <10
- 圈外人理解需要先理解一个更大的领域

**典型**：

```
HNSW 算法 / BERT 的 attention / Pinecone 这家公司 / 《XX 这本书》
```

**push back 模板**：

> "XX 是 YY 领域里的一个具体点。建议：
> - 如果你想深挖这一个点 → 用 prism-research（专门做单点深度）
> - 如果你想先建立 YY 大盘认知再回来看这个点 → 用本 skill 跑 YY，写完再看 XX 就懂了
>
> 你想要哪个？"

## Q2. 成熟度

### 成熟期

**信号**：

- 玩家格局稳定 ≥3 年（Top 5 没换过）
- 主流叙事统一，没有公开撕逼的流派之争
- 财报、十年图表、行业蓝皮书都现成
- 估值/收入指标有共识基准

**骨架重心调整**：

- 玩家地图 ⭐ 加重——格局稳定值得详细绘
- 矛盾结构降级——成熟领域大矛盾已被吸收为存量博弈
- 时间轴拉长——可以追到 20 年前
- 学习路径——更多体系化教材，少一手信源

**例**：

- 美国 SaaS 行业（玩家地图为主）
- 日本便利店产业（玩家地图 + 时间轴）
- 传统商业银行（玩家地图 + 矛盾结构-监管）

### 新兴期 ⭐（最容易翻车）

**信号**：

- Top 玩家 1~2 年内会换
- 主流叙事在打架（不止一种"正确答案"）
- 没有十年图表，只有融资新闻
- "XX 是什么"圈内人自己都没共识

**骨架重心调整**：

- 矛盾结构 ⭐⭐ 加重——分歧本身就是这个领域的形态
- 不确定性 ⭐⭐ 必须显式标注——禁止伪装成稳定
- 玩家地图——必须含"还没下场但即将下场"的玩家
- 时间轴——重点是"未来 12 个月可能发生的拐点"
- 反身性 ⭐⭐⭐——主流叙事在塑造现实，必须显式拆穿

**警示**：新兴领域**不准用成熟期的笔法写**。"XX 已经成为 YY"、"XX 锁定领导地位" 这类句子在新兴领域里都是 AI Slop——没人锁定，因为根本没格局。

**例**：

- World Model（争议结构）
- 具身智能（流派分歧）
- 公募 REITs in 中国（监管+市场双新兴）

### 衰退期

**信号**：

- 收入/用户规模连续 ≥2 年下滑
- 老玩家退场（破产/被收购/转型）
- "为什么会死"开始成为内行话题
- 替代品已成型

**骨架重心调整**：

- 教训抽取 ⭐⭐——这是衰退领域的核心价值
- 时间轴——重点是"从巅峰到现在的衰退路径"
- 矛盾结构——内部派系是怎么撕的
- 学习路径——更多是"事后复盘"的材料

**例**：

- 黑莓生态（教训：开放生态 vs 封闭生态）
- 美国传统报业（教训：分类广告被 Craigslist 拆解）
- 日本游戏机（教训：从主机到手游的迁移失败）

## Q3. 用户先验水平

### 零基础

**判别**：用户从未在简历/聊天中提及任何相关词。

**输出适配**：

- 黑话密度低——所有圈内缩写第一次出现都展开
- 类比多——用日常事物类比技术概念
- 跳过一切"对内行显而易见"的细节
- 加大"why this matters"段——为什么你应该关心

### 邻域转入（默认）

**判别**：用户技术能力强，但没在这个具体领域待过。

**输出适配**：

- 黑话密度中——圈内缩写第一次展开后续直接用
- 强调"和你已知领域的差异"——比如对程序员讲金融，重点是"不要把 OOP 思路套到产品架构上"
- 跳过基础概念但不跳过**反直觉概念**

### 有基础求拓宽

**判别**：用户在这个领域待过 ≥1 年，想要的是新视角而不是入门。

**输出适配**：

- 黑话直接用——不展开
- 重点放在**矛盾结构、流派分歧、时间尺度套利**——这是用户没接触过的视角
- 不要写"XX 是 YY"这种入门句
- 加重反身性——指出主流叙事的盲区

**用户没明说时**：默认"邻域转入"。

## 决策树的失败模式

**最常见的两个错误**：

1. **不分类直接开写**——用户说"了解 AI"你就开始写 AI 大盘，写出来一定是水稿。颗粒度判断必须是第一动作。

2. **分类对了但没和用户对齐**——你判断为"中等 + 新兴 + 邻域转入"，但用户其实是 PhD 想要前沿争议——这种对齐 30 秒就能完成，省下 30 分钟返工。

**对齐协议见 SKILL.md 中的 Step 1 输出格式**。
