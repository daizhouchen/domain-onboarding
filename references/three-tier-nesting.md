# 三档嵌套规范 · Three-Tier Nesting

> **核心原则：嵌套，不替代**
> 闪研 ⊂ 精研 ⊂ 深研。用户切档不是"换文档"，是"展开/收起更多内容"。

---

## 三档定义与必含元素

```
┌─────────────────────────────────────────────────────────────────┐
│  ⚡ 闪研 30min  ──→ 📖 精研 60min  ──→ 🔬 深研 90min            │
│   骨架 + 黑话      闪研 + 机制 + 反身性      精研 + 结构 + 范式  │
└─────────────────────────────────────────────────────────────────┘
```

### ⚡ 闪研档（Flash · 30 分钟）必含元素
- [ ] 一句话定义（≤ 25 字）
- [ ] 骨架五件套精简版（每件 1-3 条要点）
- [ ] 黑话表（10-15 个最高频术语）
- [ ] 3 个最重要事实锚点（必须 A 级源）
- [ ] 已知的未知清单 ≥ 3 条
- [ ] AI 视角 disclaimer（精简版，约 80 字）
- [ ] 来源分级表（精简）

### 📖 精研档（Standard · 60 分钟）必含元素
**= 闪研全部 + 以下增量：**
- [ ] 玩家地图（含上下游关系）
- [ ] 时间轴（5-10 个关键拐点）
- [ ] 矛盾结构（≥ 3 组核心争议）
- [ ] **机制层**完整章节（壁垒/规模效应/锁定从哪来）
- [ ] **反身性元透镜**章节（主流叙事 + 失效条件）
- [ ] 行业认知误区 ≥ 3 + 局内人盲区 ≥ 2
- [ ] 完整黑话表（4 类 jargon）
- [ ] 推荐人/账号/会议/社区 ≥ 3
- [ ] 已知的未知 ≥ 5 条
- [ ] AI 视角 disclaimer（标准版，约 150 字）
- [ ] 完整来源分级表

### 🔬 深研档（Deep · 90 分钟）必含元素
**= 精研全部 + 以下增量：**
- [ ] **结构层**完整章节（reality-shaping 约束）
- [ ] **范式层**完整章节（硬核 / 异端 / 范式松动信号）
- [ ] **跨领域同构案例 ≥ 2**（历史 + 邻接领域）
- [ ] 学习路径完整版（next reading 清单 + 顺序 + 时长估计）
- [ ] 自检题 ≥ 10 道（让用户测试自己理解程度）
- [ ] 已知的未知 ≥ 8 条
- [ ] 同构点 vs 反同构点对比表
- [ ] 范式松动信号清单（≥ 3 个）
- [ ] 延伸阅读 / 分析工具索引（学者名 / 书目 / 论文）

## HTML 实现规范

### CSS class 命名约定

```html
<!-- 三档可见性控制 -->
<body class="tier-flash">     <!-- 默认闪研 -->
<body class="tier-standard">  <!-- 精研 -->
<body class="tier-deep">      <!-- 深研 -->

<!-- 内容元素打标 -->
<section data-tier="flash">    <!-- 闪研档就有 -->
<section data-tier="standard"> <!-- 精研开始才有 -->
<section data-tier="deep">     <!-- 深研专属 -->
```

### CSS 切换核心规则

```css
/* 闪研：只显示 flash 标记的内容 */
body.tier-flash [data-tier="standard"],
body.tier-flash [data-tier="deep"] { display: none; }

/* 精研：显示 flash + standard */
body.tier-standard [data-tier="deep"] { display: none; }

/* 深研：全显示（默认行为） */

/* 切档动画：用 max-height 过渡，避免突兀 */
[data-tier] {
  overflow: hidden;
  transition: max-height 0.4s ease, opacity 0.3s ease;
}
```

### 切档按钮（HTML 头部）

```html
<nav class="tier-switcher" role="tablist">
  <button data-set-tier="flash"    class="active">⚡ 闪研 30min</button>
  <button data-set-tier="standard">📖 精研 60min</button>
  <button data-set-tier="deep">    🔬 深研 90min</button>
</nav>
```

## 用户体验规则（不丢已读内容）

切档时**不刷新页面、不重置滚动位置、不丢已读标记**：

| UX 问题 | 错误做法 | 正确做法 |
|---------|---------|----------|
| 切档时丢失滚动位置 | location.reload() | 仅 toggle body class |
| 切档时丢失已读 | 重写 DOM | 用 CSS class 控制显示，DOM 保留 |
| 升档后用户找不到已读位置 | 默认滚到顶 | 滚动锚定到当前 section 起点 |
| 降档后内容突然消失 | display:none 直接切 | 0.4s 高度+透明度过渡 |
| 切档状态丢失（刷新页面） | 不存 | localStorage 存 `domain-tier` |

```javascript
// 简洁版（嵌入 HTML 末尾）
document.querySelectorAll('[data-set-tier]').forEach(btn => {
  btn.addEventListener('click', () => {
    const tier = btn.dataset.setTier;
    document.body.className = `tier-${tier}`;
    localStorage.setItem('domain-tier', tier);
    // 滚动锚定：保留当前可见 section
    document.querySelectorAll('[data-set-tier]')
      .forEach(b => b.classList.toggle('active', b === btn));
  });
});
// 启动时恢复
const savedTier = localStorage.getItem('domain-tier') || 'flash';
document.body.className = `tier-${savedTier}`;
```

## 三档字数差异化比例（quality_check.py 扫描）

| 档位 | 最少字数 | 与上一档比例 | 强制最低事实锚点 |
|------|---------|--------------|------------------|
| ⚡ 闪研 | 2000 字 | — | 15 |
| 📖 精研 | ≥ 1.3 × 闪研字数 | ≥ 130% | 35 |
| 🔬 深研 | ≥ 1.5 × 精研字数 | ≥ 150% | 70 |

举例：闪研 3000 字 → 精研 ≥ 3900 字 → 深研 ≥ 5850 字。
**比例不达标 = 视觉闸门红 = 必返工**。

> **比例不是字数堆砌**——增量必须是新章节、新分析、新事实，不是把同一段话写得更啰嗦。
> quality_check.py 还会扫"重复段落相似度"——同一段话换皮重写 ≥ 80% 相似度 = 红。

## REITs 领域 · 三档示例

### ⚡ 闪研 30min · 约 300 字 demo

> **REITs · 一句话**：把不动产打包成证券化基金，让你像买股票一样持有"楼"的一部分。
>
> **骨架精简**：
> - 玩家头部：CapitaLand（新加坡）/ Equinix（数据中心）/ Public Storage（仓储）
> - 矛盾核心：分红 vs 增长——按法律分红 ≥ 90% 利润 → 留存少 → 增长靠融资
> - 时间拐点：1960 美国立法允许 / 2000 数据中心 REITs 兴起 / 2020 中国试点
>
> **3 个事实锚点**：① 全球 REITs 市值 ≈ $2.5T（NAREIT, 2023）。② 美国 REITs 长期年化总回报 ≈ 11.6%，跟标普 500 接近，但分红占比更高。③ 中国 REITs 2023 年首批扩募规模 ≈ ¥120B（公募基金）。
>
> **3 个高频黑话**：FFO（funds from operations，比 GAAP 利润更准的现金流指标）、AFFO（再扣维护资本支出）、Cap Rate（资本化率，租金/估值，相当于反向 PE）。
>
> **未知清单**：① 中国试点扩募后退出机制如何？② 利率长期高位下 REITs 的相对吸引力？③ 数据中心 REITs 是否会因为 AI 算力需求被重估？

---

### 📖 精研 60min · 约 380 字 demo（增量部分）

> **机制层（精研增量）**：
> REITs 的真正壁垒在三个地方——
> ① **税务结构**：分红 ≥ 90% 利润换免企业所得税，相当于"穿透"。这是它的核心。
> ② **资产规模**：单个商场 / 数据中心动辄 $10-100M，分散持有不可能。规模效应来自资产端。
> ③ **运营专业化**：商场招租、数据中心电力调度、仓储自动化——管理能力本身是壁垒。
>
> **反身性元透镜（精研增量）**：
> 主流叙事："REITs = 类债券、抗通胀、稳分红"。这个叙事吸引保守资金 → 估值在低利率时被推高 → 大众更信稳定 → 更多资金 → 形成正循环。
> **失效条件**：长期高利率（超过 5% 持续 18 个月）+ 商业地产空置率 > 15% + 一两个标杆 REITs 暴雷。三个一起来时，"类债券"叙事崩塌。2023 年办公 REITs 跌幅 ≥ 35% 就是范例。

---

### 🔬 深研 90min · 约 380 字 demo（深研增量）

> **结构层（深研增量）**：
> 这个赛道有四个 reality-shaping 约束——
> ① **税法约束**：分红比例硬指标，全球大部分国家照搬美国。改不了。
> ② **会计约束**：FFO 成为行业事实标准，但缺乏 GAAP 强制 → 各家口径不一，给操纵空间。
> ③ **资产 vs 现金流的错配**：商业地产估值随利率波动剧烈，但租金现金流相对刚性。错配是 REITs 周期性的根。
> ④ **REITs 的退出依赖二级市场**：与私募地产基金不同，REITs 不能"挺过去"——价格天天报，跌就是跌。
>
> **跨领域同构（深研专属）**：
> 同构 1 · BDC（Business Development Company）—— 90% 分红 / 类似的税务穿透 / 但底层是私募贷款不是地产。
> 同构 2 · MLP（Master Limited Partnership）—— 90% 分红 / 底层是油气管道。
> **同构点**：税务结构 + 资产证券化 + 强分红 → 估值更接近债券。
> **反同构点**：底层资产风险结构完全不同——地产周期 vs 信贷周期 vs 大宗商品周期。
>
> **学习路径完整版**：① NAREIT 网站官方文档 → ② Green Street Advisors 行业报告 → ③ 《REITs 投资圣经》Ralph L. Block → ④ 跟踪 Vornado / Boston Properties 财报学办公 REITs，跟踪 Equinix / Digital Realty 学数据中心 REITs。

## 三档实现 checklist（写完后自检）

- [ ] 同一份 HTML，三档都在同一个文件里？（不是三个独立文件）
- [ ] 切档按钮在头部固定可见？
- [ ] 切档动画 ≤ 0.5s 完成？
- [ ] 切档不丢滚动位置？
- [ ] localStorage 存了用户上次选的档位？
- [ ] 字数比例达标？（精研 ≥ 1.3× 闪研，深研 ≥ 1.5× 精研）
- [ ] 增量内容是真的新章节，不是同一段话改写？
- [ ] 闪研档去掉机制层和结构层后，仍然能让用户"30 分钟读完不亏"？
- [ ] 精研档加机制 + 反身性后，比闪研多 30% 字数都用在新洞察上？
- [ ] 深研档加结构 + 范式 + 同构后，比精研多 50% 字数都用在新洞察上？
