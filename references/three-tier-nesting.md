# 深度产物厚度规范 · Depth Bar Spec

> v1.0 单档定位：删了闪研/精研/深研三档切换，只保留深研档作为唯一深度产物。
> 文件名保留 `three-tier-nesting.md` 是为了向后兼容外部引用——内容已重写。

---

## 单档深度产物的核心定位

**目标读者**：愿意花 60-90 分钟系统性吃透一个领域的人。

不是"30 分钟扫盲"，不是"点开看两眼"——是"我下周要见客户/老板让我评估/我想转行，
我需要一份能撑起决策的真材实料的领域地图"。

**专注极致**：单档让我们可以把所有写作精力集中在一份产物上，不用在三档之间分摊深度。
这是设计选择，不是减法——v0.x 的三档切换在实测中几乎没人用，多数用户直接读最深的那档。

---

## 硬指标清单（质量闸门会扫）

一份合格的深度产物必须同时满足以下指标：

| 维度 | 下限 | 闸门 |
|------|------|------|
| 事实锚点（fact-N 上标 + 完整清单） | ≥ 70 条 | quality_check（warning） |
| A+B 级源占比 | ≥ 60% | quality_check（fail） |
| 机制段落（`p.mechanism` with `data-fact-refs`） | ≥ 18 条，每条引用 ≥3 个 fact | quality_check（fail） |
| 观点段落（`blockquote.viewpoint` with `.counter`） | ≥ 14 条，每条带反例 | quality_check（fail） |
| 已知的未知（`#known-unknowns` 旁路 ul） | ≥ 12 条 | quality_check（fail） |
| 跨学科调用（章七的同构案例 + 各章的工具借用） | ≥ 6 把刀 | 写作时自检 |
| 字数（plain text） | ≥ 22000 字 | 写作时自检 |
| 推荐人/账号/社区（`details.experts-fold > li`） | ≥ 3 条 | quality_check（fail） |

> 事实密度未达标 X1 阶段是 warning（X2 在并行加深内容）；其余指标是 fail。

## 章节弧线（10 章必含）

```
一、这是什么 · 为什么现在值得花一小时
二、它怎么走到今天
三、谁在场上 · 谁在赌什么
四、圈内人才懂的几件事
五、表面之下 · 几条不可变的约束
六、这是什么时期 · 异端正从边缘浮现
七、别处的故事 · 镜照本地（≥2 个跨领域同构 + 同构点 / 反同构点）
八、主流叙事 · 它如何自我强化又如何崩
九、接下来你应该读什么 · 信谁
十、我（AI）不知道的几件事
```

每一章都不可省。前四章建立"故事+玩家+取舍"，五-八章是"约束→范式→镜照→反身性"
四层结构层级递进，九-十章是"路径+边界"。少任何一章这份产物就不是"深度产物"。

## "深度"的具体含义

不是字数堆砌，是**多个维度同时达标**：

1. **事实密度**：每千字至少 3 个事实锚点，且至少 60% 来自 A/B 级源。
2. **机制密度**：每个核心论点背后必须有显式的"为什么必须这样"段落，
   且这个段落至少引用 3 个事实。
3. **反例密度**：每个观点都必须带反例或证伪条件——`<blockquote class="viewpoint">`
   内必须有 `<span class="counter">`。
4. **跨学科调用**：章七至少 2 个跨领域同构案例（一历史 + 一邻接领域），
   再加上其他章节里"借一把刀"（行为经济学、博弈论、组织行为学等）合计 ≥6 处。
5. **不确定性显式化**：`#known-unknowns` 节点必须 ≥12 条；
   章十"我（AI）不知道的几件事"是叙事化版本。

## HTML 实现规范（v1.0 单档）

### 章节渲染

```html
<section class="chapter" id="chapter-{id}">
  <h2>章节标题</h2>
  {{ narrative_html }}
</section>
```

不再有 `tier-flash / tier-medium / tier-deep` class 区分——所有章节平等渲染。

### 主题切换（保留）

`<button class="theme-btn" id="theme-toggle">` 仍在，明暗模式可切；
档位切换器（`<nav class="tier-bar">`）已删。

### 打印优化（A4）

`@page { size: A4; margin: 1.6cm; }` 默认开启。整份产物可直接打印归档。

## 写作 checklist（写完后自检）

- [ ] 10 章是否齐全？每章是否都有 narrative_html？
- [ ] 事实锚点 ≥ 70 条，且每条都有 source 和 grade？
- [ ] A+B 级源占比 ≥ 60%？
- [ ] 机制段落 ≥ 18 条，每条 `data-fact-refs` 引用 ≥3 个事实？
- [ ] 观点段落 ≥ 14 条，每条都有 `.counter` 反例？
- [ ] `#known-unknowns` ≥ 12 条？
- [ ] 章七至少 2 个跨领域同构 + 同构点 + 反同构点？
- [ ] 跨学科调用合计 ≥ 6 处？
- [ ] H1/H2/H3 不出现"事实层/机制层/观点层/反身性/结构层/范式层"等框架名？
- [ ] 推荐人 ≥ 3 个真名 + 上下文？
- [ ] 自检题 ≥ 10 道（嵌在 `details.self-check-fold` 折叠区）？
- [ ] AI 自反性 disclaimer（cutoff date + "AI 是主流叙事载体"）在尾跋？

## 与 v0.x 三档定位的对比

| 维度 | v0.x（三档） | v1.0（单档） |
|------|--------------|--------------|
| 用户决策成本 | 选档位 + 切档位 | 0（无需选择） |
| 产物聚焦度 | 在三档间分摊 | 全力投入一档 |
| 实测使用情况 | 多数用户读最深的那档 | 直接给最深的 |
| 写作成本 | 写一份做三套裁剪 | 写一份做透 |
| 闸门复杂度 | tier-aware 多套阈值 | 单套阈值 |
| 哲学一致性 | 多档稀释专注 | 专注极致 |

> "30 分钟扫盲"和"90 分钟深研"不是同一个 skill 应该解决的事——
> 扫盲场景已经有维基百科、State of X Report、Hacker News 顶贴；
> domain-onboarding 应该专注于**没人能给你做的那一档**：60-90 分钟的系统性深度地图。
